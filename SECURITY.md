# Security policy

## Supported versions
Only the latest release of `@arffornia/nexus_mods` (built from `main`) receives fixes.

## Reporting a vulnerability
Please report privately via GitHub: **Security → Report a vulnerability** on
[Arffornia/Nexus_Mods](https://github.com/Arffornia/Nexus_Mods/security/advisories/new).
Do not open a public issue for an unfixed vulnerability.
